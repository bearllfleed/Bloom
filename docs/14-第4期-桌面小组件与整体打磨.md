## 2. 页面设计

### 4-1 iOS 小组件

**小号 · 今日进度**

```
┌──────────────────┐
│ 今天         (朵朵) │  朵朵头像按进度换表情
│                  │
│   （花苞进度环）     │  环按项目数分段，完成段为莓果 500
│       2/3        │  数字中
│                  │
│ 还差 1 个          │  辅助
└──────────────────┘
```

| 状态 | 显示 |
|---|---|
| 有未完成 | 进度环 + "还差 N 个" |
| 全部完成 | 中间换成带笑脸的盛开花朵 + "全开啦" |
| 休息日 | 朵朵犯困 + "今天休息" |
| 没有项目 | 朵朵捧种子 + "去种第一朵花" |
| 数据超过 2 天未刷新 | "打开 Bloom 刷新一下" |

点击任意位置打开今日页。

**中号 · 今日列表（可打卡）**

```
┌──────────────────────────────────────┐
│ 11月22日 周日       │ (贴纸) 早睡    (花苞) │
│                   │ (贴纸) 喝水 3/8 (分段) │
│  （进度环 2/3）      │ (贴纸) 八段锦  (盛开) │
│  还差 1 个          │          还有 2 个 >  │
└──────────────────────────────────────┘
```

- 最多 3 行；**组件里未完成的排在前面**（与 App 内的固定顺序不同，因为组件空间有限，要让还没做的先露出来）。
- 点花苞：直接打卡（iOS 17 交互组件），按钮立即切换状态，数字用系统数字过渡。多次项目每点一次 +1。
- 点已完成的花：打开 App 并定位到该项目（撤销在 App 内完成，避免在桌面误撤销）。
- 点名称或空白处：打开 App 并定位到该项目。

**大号 · 本月花园**

```
┌──────────────────────────────────────┐
│ 2026年11月                  完成 18 天 │
│  一  二  三  四  五  六  日             │
│  迷你月历（花朵三态，今天描边）            │
│ ─────────────────────────────         │
│ (贴纸) 早睡                      (花苞) │
│ (贴纸) 喝水         3/8          (分段) │
│ (贴纸) 八段锦                    (盛开) │
│ (贴纸) 背单词                    (花苞) │
└──────────────────────────────────────┘
```

**单项目**（可配置）

```
┌──────────────────┐
│ (贴纸 44)         │  底色为项目浅色
│ 早睡              │
│ 连续 12 天         │
│          (花苞 44) │  可直接打卡
└──────────────────┘
```

**锁屏**
- 圆形：进度环 + "2/3"。
- 矩形："还差 1 个 · 早睡"，全部完成时"今天全部完成"。
- 单行："Bloom 2/3"。

### 4-2 Android 小组件

| 尺寸 | 对应 iOS | 说明 |
|---|---|---|
| 2×2 | 小号 | 同上 |
| 4×2 | 中号 | 花苞按钮可点击打卡 |
| 4×4 | 大号 | 同上 |
| 2×2 单项目 | 单项目 | 添加时进入项目选择 |

- 支持拖动调整大小，小于标准尺寸时隐藏次要文字。
- Android 12 以上使用系统圆角；每个组件提供添加时的预览图。
- 点击打卡后组件立即刷新（无动画，由系统限制）。

### 4-3 单项目组件的项目选择

- iOS：长按组件 → 编辑小组件 → 选择项目（列表显示图标和名称）。
- Android：添加组件时弹出选择页（与 App 风格一致的列表），之后长按组件可重新选择。
- 所选项目被删除：组件显示"这个项目不见了，长按重新选一个"。
- 所选项目已暂停/已毕业：组件灰度显示"休息中"/"已毕业"，不可打卡。

### 4-4 数据同步规则

见 `01-技术方案.md` 第 11 节。本期补充交互层面的规则：

| 场景 | 表现 |
|---|---|
| 在 App 内打卡/撤销/改项目 | 5 秒内组件更新 |
| 在组件上打卡 | 组件立即更新；下次打开 App 时记录入库，来源为"小组件"；打卡记录中显示来源 |
| 组件打卡解锁徽章 | 下次打开 App 600ms 后弹出 |
| 零点（按一天结束时间） | 不打开 App，组件也切换到新的一天 |
| 超过 2 天未打开 App | 组件提示"打开 Bloom 刷新一下"，此时不可打卡 |
| 第一次用组件打卡 | 解锁徽章"桌面花园" |

### 4-5 分享图

| 图 | 尺寸 | 入口 | 内容 |
|---|---|---|---|
| 毕业证书 | 1080×1440 | 毕业典礼、回顾页右上角 | 证书全文 + 底部小字 Bloom |
| 年度花园 | 1080×1920 | 统计 · 年 右上角 | "小桃的 2026 花园"、12 个月热力图、4 个年度数字、完成最多的项目、朵朵、Bloom |
| 项目月卡 | 1080×1350 | 项目详情月历卡片的"更多" | 项目头卡、当月花朵月历、本月完成与最长连续 |

```
┌──────────────────────────────────────┐
│                ━━━━━                  │
│ ┌──────────────────────────────────┐ │
│ │        （分享图缩略预览）             │ │
│ └──────────────────────────────────┘ │
│ 显示昵称                       (开关)   │
│ [         保存到相册          ]         │
│ [         发送到……            ]         │
└──────────────────────────────────────┘
```

- 保存到相册只申请"仅添加照片"权限；拒绝时提示"相册权限没打开"+"去设置"。
- 成功提示"已保存到相册"。
- 分享图使用 App 内同一套组件离屏渲染为图片，保证与界面一致。

### 4-6 彩蛋

- **荡秋千**（M29）：今日页列表在顶部继续下拉超过 80px，朵朵荡着秋千从顶部垂下，并冒出一句随机鼓励语；松手后荡回。
- **连点朵朵**：1.5 秒内连点顶部朵朵 5 次，朵朵原地转一圈，气泡"别戳啦，好痒"。

### 4-9 深色模式

色板与规则见 `02-设计规范.md` 3.8。第 0 期起所有组件都走语义变量，本期的工作是"接上开关 + 逐页走查 + 处理例外"。

**外观设置**：偏好设置新增一行"外观"，分段控件"跟随系统 / 浅色 / 深色"，默认跟随系统。切换时整屏颜色 240ms 交叉过渡，不闪白。

**逐页处理的例外**

| 位置 | 深色下的处理 |
|---|---|
| 朵朵、贴纸图标、徽章 | 颜色不变，外加 2px 奶油色外描边（90% 透明度） |
| 花朵三态 | 小圆点改为分隔线色 #3D3238；花苞、盛开不变 |
| 完美日花瓣雨、彩纸 | 颜色不变，粒子透明度降到 85%，避免刺眼 |
| 徽章弹窗遮罩 | 改为黑色 60% |
| 毕业证书、分享图 | 始终浅色纸质感；在深色界面中证书四周加一圈柔和的暖光晕（纸张被台灯照亮的感觉） |
| 照片查看 | 不变（本来就是深色背景） |
| 启动页 | 跟随系统外观提供两版 |
| 小组件 | iOS、Android 都提供深色版，跟随系统 |
| Android 状态栏/导航栏 | 图标颜色随外观切换 |

## 3. 整体打磨清单

### 3.1 无障碍
- [ ] 全部图标按钮、花苞、日期格、徽章都有读屏描述
- [ ] 用 VoiceOver 与 TalkBack 能完成：新建项目、打卡、撤销、补卡、查看统计
- [ ] 系统字体放大到 1.3 倍，全部页面无重叠、无截断
- [ ] 对比度抽查：所有正文 ≥ 4.5:1

### 3.2 动效
- [ ] 设计规范 9.3 的 30 个动效逐一核对（时长、缓动、触感）
- [ ] 开启减弱动态：所有庆祝类动效降级为淡入淡出
- [ ] 无多余的循环动画

### 3.3 屏幕与机型
- [ ] iPhone SE（小屏）、iPhone 标准款、iPhone Pro Max
- [ ] 安卓 720p 低分辨率屏、全面屏、带挖孔/刘海屏
- [ ] 小米、华为（鸿蒙 4）、荣耀、OPPO、vivo 各一台实测提醒与小组件

### 3.4 边界情况
- [ ] 手机存储不足时：导出、添加照片给出明确提示，不产生半截文件
- [ ] 相册、相机、通知权限拒绝后的引导
- [ ] 手动把系统时间改到过去：不崩溃，"今天"跟随系统时间
- [ ] 切换时区：按手机当前时区计算"今天"
- [ ] 压力数据：20 个项目 × 5 年记录 × 300 篇心情
- [ ] 连续 50 次快速打卡/撤销不出现记录错乱

### 3.5 文案与视觉
- [ ] 全部界面文字来自文案库；无解释界面的文字、无占位文字、无 emoji
- [ ] 视觉走查清单（设计规范第 12 节）每页截图评审两轮，每轮只改影响最大的 1–3 处
- [ ] 应用图标、启动页、通知图标（Android 单色小图标）在深浅桌面上都清晰

### 3.6 性能
- [ ] 达到 `01-技术方案.md` 第 19 节全部指标
- [ ] 包体：清理未使用的字体字重和资源

## 7. 风险

| 风险 | 应对 |
|---|---|
| iOS 组件打卡后当天提醒仍会响 | 预研在扩展内取消对应提醒；不可行时在提醒文案上无影响，接受该限制并写进更新说明 |
| Android 各厂商桌面对组件的限制不同 | 主流机型实测，问题机型降级为只显示不打卡 |
| 打磨项多、时间不够 | 打磨清单按"影响每天使用"优先排序，彩蛋最后做，可顺延到 1.0.1 |
| 深色模式遗漏页面 | 第 0 期起组件陈列页有"深色预览"，各期开发时顺带检查；本期走查按页面清单逐页截图 |
