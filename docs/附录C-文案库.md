## 15. 提醒检查 · 厂商后台设置说明

以下步骤为初稿，第 2 期在对应品牌真机上逐一核对后修订（系统版本不同，菜单名称会有差异）。

| 品牌 | 步骤 |
|---|---|
| 小米 / 红米 | ① 设置 → 应用设置 → 应用管理 → Bloom ② 省电策略 → 无限制 ③ 自启动 → 打开 |
| 华为（鸿蒙 4 及以下） | ① 设置 → 应用和服务 → 应用启动管理 ② 找到 Bloom，关闭"自动管理" ③ 打开"允许自启动""允许后台活动" |
| 荣耀 | ① 设置 → 应用 → 应用启动管理 ② 找到 Bloom，改为手动管理 ③ 打开全部三项 |
| OPPO / 一加 / realme | ① 设置 → 电池 → 更多设置 → 优化电池使用 ② 找到 Bloom，选"不优化" ③ 应用管理 → Bloom → 允许自启动 |
| vivo / iQOO | ① 设置 → 电池 → 后台耗电管理 ② 找到 Bloom，选"允许后台高耗电" ③ i 管家 → 应用管理 → 自启动 → 打开 Bloom |
| 三星 | ① 设置 → 电池 → 后台使用限制 ② 把 Bloom 加入"从不休眠的应用" |
| iOS | 专注模式开启时提醒可能不会响 |
