### 3-3 徽章弹窗

```
┌──────────────────────────────────────┐
│ （墨 900 45% 遮罩）                      │
│            ╲   │   ╱                  │  光芒（繁花、彩虹花等级）
│   ┌──────────────────────────────┐   │
│   │          ▬ 新徽章 ▬           │   │  SVG 缎带 + 文字
│   │                              │   │
│   │        （徽章 180pt）          │   │
│   │                              │   │
│   │           一周花开             │   │  标题 1
│   │     「早睡」连续打卡 7 天        │   │  正文 墨 600
│   │       繁花 · 11月22日获得       │   │  辅助 墨 400
│   │  [           收下啦          ] │   │
│   │           去成就馆看看          │   │
│   └──────────────────────────────┘   │
│                ●  ○  ○                │  多枚时的进度点
│             一次收下 3 枚                │  剩余 ≥ 3 枚时
└──────────────────────────────────────┘
```

**弹出时机**
- 触发动作的动画结束后再弹：打卡绽放（520ms）、若同时有完美日庆祝再等庆祝结束，之后 300ms。
- 用户在连续打卡时不打断：最后一次点击后静止 1.2 秒才弹出。
- 小组件打卡解锁的徽章：下次回到 App 时，延迟 600ms 弹出。

**动效时间线（M19，约 1400ms）**

| 时间 | 动作 |
|---|---|
| 0ms | 遮罩淡入（200ms） |
| 100ms | 卡片从下方 40px 处上移，同时从 0.92 放大到 1（柔和弹簧） |
| 250ms | 徽章从 0 弹到 1.15 再回到 1，同时由 -15° 转正（弹跳弹簧）；触感成功 |
| 400ms | 光芒淡入并开始慢转（12 秒一圈，弹窗打开期间持续） |
| 500–900ms | 星星点缀依次闪烁 |
| 600ms | 高光从左上到右下扫过一次（600ms） |
| 650ms | 文字依次淡入上移（间隔 60ms） |
| 700ms | 从徽章中心喷出 40 片花瓣彩纸，1.4 秒落完 |
| 彩虹花额外 | 徽章外圈画出一圈彩虹环（600ms），彩纸多一波 |

**按钮**
- 收下啦：徽章沿弧线飞向"成就"页签（M20），页签图标弹跳；当前页没有标签栏时改为淡出。有下一枚时 300ms 后从右侧滑入。
- 去成就馆看看：关闭弹窗并跳到成就页签，定位到这枚徽章；队列中剩下的徽章标为已展示，在成就馆里带"新"圆点。
- 一次收下 3 枚：剩余徽章以 80ms 间隔依次飞向页签。
- Android 返回键 = 收下啦。点遮罩不关闭（防误触）。
- 减弱动态：只有淡入淡出，无光芒、无彩纸、无飞行。

- **表情**：点选播放 M30；再点一次取消选择。
- **文字**：≤ 500 字；输入到上限后无法继续输入；粘贴超长内容截断并提示"最多 500 字哦"。
- **照片**：点"＋"弹出"从相册选 / 拍一张"；相册多选上限为剩余张数；相机权限在第一次拍照时申请。选中后压缩（长边 1920、质量 0.8）并生成缩略图，处理中格子显示花瓣转圈；失败的格子显示"重试"。长按拖动调整顺序；点右上角小叉删除（保存前可再加回，不确认）；点照片进入图片查看。
- **保存**：表情、文字、照片至少有一项时"保存"可用；保存后返回并提示"记下啦"，入口图标同步变化。
- **草稿**：每 2 秒及 App 切到后台时自动保存草稿；再次进入同一天同一项目的编辑页时恢复，并提示"接着上次写"。保存或放弃后清除草稿。
- **离开**：有未保存内容时点取消或下滑：确认框"放弃这次心情吗"，按钮"继续写 / 放弃"。
- 已有心情时进入即为编辑，标题栏右侧"更多"中可删除。

## 3. 成就引擎规则

- 徽章清单、条件、等级、解锁节奏见 `附录A-成就清单.md`。
- 判定基于历史最大值，补卡同样能解锁；撤销、删除不收回。
- 每次结算只处理受影响的指标（事件 → 指标映射）。
- 首次升级到本期版本、导入备份后执行静默结算，结果合并进补发卡；结算出 ≥ 5 枚时也合并为补发卡，< 5 枚则逐个弹出。

## 4. 验收标准

### 4.1 功能断言

| 编号 | 断言 |
|---|---|
| A3-01 | 开发版徽章陈列页中 72 枚徽章在三种模式（弹窗、详情、网格）下全部正常渲染 |
| A3-02 | 每枚徽章都有单测：达到阈值时解锁，差 1 时不解锁 |
| A3-03 | 新安装后创建第一个项目并打卡：依次弹出"种下种子""第一朵花" |
| A3-04 | 一次操作解锁 3 枚：依次弹出，有进度点和"一次收下 3 枚" |
| A3-05 | 连续快速打卡多个项目：弹窗在停手 1.2 秒后出现 |
| A3-06 | 弹窗显示时杀掉 App：下次启动补弹 |
| A3-07 | 撤销刚才导致解锁的打卡：徽章仍在 |
| A3-08 | 带 60 天数据从第 2 期升级：首次打开显示补发卡，成就馆状态与数据一致 |
| A3-09 | 导入备份后：已获徽章与备份一致；新满足条件的合并进补发卡 |
| A3-10 | 未获得的隐藏徽章不显示条件 |
| A3-11 | 心情入口只在完成后出现；未完成、未来日期不出现 |
| A3-12 | 粘贴 600 字：截断为 500 字并提示 |
| A3-13 | 照片最多 5 张；压缩后单张 ≤ 1MB |
| A3-14 | 写到一半杀掉 App：再次进入恢复草稿并提示 |
| A3-15 | 撤销打卡后心情仍在；删除项目后心情显示"已删除的项目" |
| A3-16 | 导出 → 导入往返：心情文字一致，照片文件哈希一致 |
| A3-17 | 心情手账"只看有照片"筛选正确 |
| A3-18 | 减弱动态下：徽章弹窗只有淡入淡出 |

### 4.2 动效与性能

- 徽章弹窗（含光芒、彩纸）在中端安卓 ≥ 55fps。
- 成就馆 72 枚徽章滚动 ≥ 55fps。
- M19、M20、M21、M30 按规范实现。

## 5. 设计交付

72 枚徽章分层 SVG（底座 12 + 图案 72 + 等级配色 4 + 数字字形 0–9 + 缎带 + 光芒 + 星星 + 礼盒问号剪影）；徽章弹窗与补发卡；成就馆与详情；5 个心情表情；心情编辑页全部状态；手账、详情、图片查看；朵朵写日记姿势；便签纸与胶带素材。

## 6. 风险

| 风险 | 应对 |
|---|---|
| 72 枚徽章设计量大 | 用"底座 × 图案 × 配色"组合降低工作量；设计在第 2 期中段开始；本期先交付前 3 个月会解锁的 60 枚，其余 12 枚可顺延到第 4 期 |
| 解锁节奏不合理 | 用时间旅行模拟 90 天典型用户（3 个每天项目，80% 完成率），核对附录 A 的节奏表 |
