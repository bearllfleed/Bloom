# 02 · 设计规范

> 本文是所有页面的共同基础。分期文档里的页面只写"用了什么、怎么排、怎么动"，具体数值都以本文为准。

## 1. 设计方向

### 1.1 方向定义

| 项 | 内容 |
|---|---|
| 产品 | 给想养成小习惯的女生用的私人打卡手账，数据只在自己手机里 |
| 性格 | 软糯、俏皮、有一点仪式感 |
| 世界 | 一本放在窗边的手账本和一个小花园：点阵纸、贴纸、和纸胶带、花苞与花、洒水壶、午后的阳光 |
| 亮点时刻 | ① 打卡时花苞绽放 ② 当天全部完成时的花瓣雨 ③ 徽章弹窗和毕业证书 |
| 签名细节 | **每一天都是一朵花**。日历格、小组件、热力图里的完美日、证书花环，都用同一套"小圆点 → 花苞 → 盛开"三态花朵 |

### 1.2 第 0 期需要先选定的三个方向

设计师用同一个"今日页"各出一版小样，选定后再铺开：

| 方向 | 关键词 | 视觉特征 |
|---|---|---|
| A 花园手账（推荐） | 温柔、日常、手作感 | 奶油点阵纸底、糖果色块、可可色墨线、花朵贯穿 |
| B 糖果贴纸 | 活泼、潮、高饱和 | 更粗的描边、贴纸投影、撞色，接近潮玩风 |
| C 云朵梦境 | 梦幻、安静、低饱和 | 粉蓝紫低饱和、云朵形卡片、星星点缀 |

本文后续数值均按方向 A 给出。

### 1.3 参考的设计技能及取舍

| 来源 | 采用 | 不采用 |
|---|---|---|
| 消费级设计系统 | 情绪优先；首屏 3 秒看到进度或奖励；空状态由角色邀请；问候语个性化；连续、徽章、里程碑等游戏化；结果可截图分享 | 玻璃拟态、3D 角色、AI 意图输入框、深棕主按钮（与卡通少女风和离线定位不符） |
| 去 AI 味（unslop） | 界面框架保持安静，颜色和细节集中在一两个亮点时刻；4px 网格；不用 emoji；不用渐变文字、发光、彩色阴影；动效只用于解释状态变化 | 完全中性灰底（卡通风需要暖色纸感） |
| 移动端视觉方向 | 尊重安全区；首屏单一焦点；避免盒子套盒子；文字不小于 11pt；多屏风格一致 | — |
| 有辨识度的设计 | 用世界观隐喻统一视觉；先出多个方向再收敛；真机截图评审，每轮只改 1–3 个最大问题 | — |

## 2. 吉祥物"朵朵"

- **形象**：奶白色小兔，圆滚滚，左耳别一朵粉色小花，脸颊有腮红，小短手。可可色 2.5px 圆头墨线。（已确认）
- **表情（6 个）**：开心、期待、加油、惊喜、犯困、疑惑。
- **姿势（11 个）**：

| 姿势 | 用在哪里 |
|---|---|
| 招手 | 欢迎页 |
| 捧着种子 | 没有任何项目时 |
| 躺在云朵上 | 当天是休息日 |
| 撒花 | 完美日横幅、补发徽章 |
| 戴学士帽捧证书 | 毕业典礼 |
| 抱着小箱子 | 备份与恢复页 |
| 摇铃铛 | 第一次申请通知权限 |
| 趴着写日记 | 心情手账为空 |
| 睡觉（带 Z 字形 SVG） | 暂停中的项目卡片角标 |
| 举放大镜 | 搜索图标无结果 |
| 荡秋千 | 今日页下拉彩蛋 |

- **今日页顶部头像**随当天进度换表情：没有项目 → 期待；有未完成 → 加油；全部完成 → 开心；休息日 → 犯困。
- **使用规则**：每屏最多出现一次；不在列表项中重复出现；不说长句，气泡最多 16 个字。

### 3.6 热力分级（5 级）

| 级 | 含义 | 色值 |
|---|---|---|
| 0 | 有计划但没完成 | #F5EEF1 |
| 1 | 完成 ≤ 1/3 | #FFD9E7 |

| 3 | 完成 > 2/3 但未全部 | #FF8DB6 |
| 4 | 完美日（格子换成小花形） | #F0588F |

单个项目的热力图用该项目颜色的浅色→深色分级。

### 3.7 用色规则

- 浅色模式下白字只出现在两处：撤销条（墨色底）和深色遮罩上。
- 不做跨色相渐变；同色深浅过渡仅用于徽章和插画内部。
- 阴影只用墨色低透明度，不用彩色阴影、不用发光。
- 每屏的高饱和色集中在亮点处（花朵、徽章、选中日期），界面框架用纸色和墨色。
- 代码中只使用"语义变量"（如"背景""卡片""主文字""分隔线"），每个语义变量都有浅色、深色两个取值，见 3.8。组件里不直接引用具体色值。

### 3.8 深色模式"夜晚花园"

- 外观设置：跟随系统（默认）/ 浅色 / 深色，位于偏好设置。
- 气质：像夜里开着小台灯的手账桌，暖调深梅色，不用纯黑。

| 语义变量 | 浅色 | 深色 |
|---|---|---|
| 背景（纸） | #FFF8F3 | #211A1E |
| 卡片 | #FFFFFF | #2C2328 |
| 凹面 | #FBF3EE | #261F23 |
| 主文字（墨 900） | #3F2A33 | #F7EEF2 |
| 次要文字（墨 600） | #7A6470 | #C9B8C0 |
| 占位/禁用（墨 400） | #B3A2AA | #8C7A83 |
| 分隔线（墨 200） | #E9DFE3 | #3D3238 |
| 弱底（墨 100） | #F5EEF1 | #33292E |
| 链接与强调文字 | #C93D72（莓果 700） | #FFA3C3（莓果 300） |
| 卡片厚边 | #EFE4E8 | #1A1417 |
| 点阵 | 墨 900 的 4% | 白色的 6% |
| 撤销条 | 墨 900 底 + 白字 | #F7EEF2 底 + 墨 900 字 |
| 热力 0–4 级 | 见 3.6 | #33292E、#5A3445、#8A3F5F、#C24F7E、#FF7BA9 |

深色模式下的规则：
- 主按钮仍为莓果 500 底 + #3F2A33 字（与浅色相同，对比度 5.4:1）。
- 项目颜色块保持原底色和 #3F2A33 字；"完成后的卡片底"改为项目底色 18% 叠在卡片色上。
- 深度靠表面明暗层级和 1px 白色 6% 细线表现，阴影减弱为 0 2 8 rgba(0,0,0,0.3)。
- 界面图标描边跟随"主文字/次要文字"变量自动变色。
- 贴纸图标、徽章、朵朵本身的颜色不变；朵朵和贴纸外加 2px 奶油色 #FFF8F3 外描边（90% 透明度），避免可可色墨线融进深色背景。
- 毕业证书、分享图始终使用浅色（纸质感），不随外观切换。
- 小组件跟随系统外观。

## 5. 间距、圆角、阴影、厚边

### 5.1 间距（4px 网格）

可用值：4、8、12、16、20、24、32、40、48。

| 场景 | 值 |
|---|---|
| 页面左右边距 | 16 |
| 卡片内边距 | 16 |
| 卡片之间 | 12 |
| 模块之间 | 24 |
| 图标与文字 | 8 |
| 模块标题与内容 | 12 |

### 5.2 圆角

| 元素 | 圆角 |
|---|---|
| 按钮、胶囊、芯片 | 高度的一半 |
| 卡片 | 20 |
| 日期格、小卡片、照片 | 12 |
| 输入框 | 14 |
| 底部面板顶部 | 28 |
| 徽章格 | 20 |
| 嵌套规则 | 内圆角 = 外圆角 − 内边距，最小 4 |

### 5.3 阴影

| 层级 | 值 | 用于 |
|---|---|---|
| 浮起 | 0 2 8 rgba(63,42,51,0.06) | 卡片 |
| 抬起 | 0 8 20 rgba(63,42,51,0.10) | 长按抬起、拖拽中 |
| 弹层 | 0 16 40 rgba(63,42,51,0.16) | 弹窗、面板 |

### 5.4 厚边（糖果按键感）

- 卡片底部 4px 实色边：白卡用 #EFE4E8；彩色块用该颜色的深色档。
- 按钮底部 4px：主按钮 #E0578C，次按钮 #EADDE2。
- 按下：按钮整体下沉 3px，厚边变为 1px；松开弹回。这是全 App 统一的"可以按"的视觉语言。

### 5.5 墨线

- 只有贴纸图标、徽章、吉祥物、花朵用可可色墨线（2–2.5px，圆头圆角）。
- 卡片和按钮不加墨线，避免画面过重。

## 6. 背景与质感

- 全局背景：纸色 #FFF8F3 + 点阵（圆点直径 1.5px、间距 16px、墨 900 的 4% 透明度），模拟手账点阵纸。点阵固定不随内容滚动。
- 庆祝、毕业、回顾、分享图可以使用和纸胶带、贴纸、印章装饰；普通页面不加装饰。
- 禁止：大面积渐变、彩色光斑、满屏毛玻璃。

## 7. 图标规范

**所有图标都是 SVG。禁止 emoji 字符、禁止把文字当图标、禁止位图图标、禁止混用第三方图标库。**

### 7.1 界面图标

- 画板 24×24，2px 圆头描边，颜色取当前文字色（SVG 中写为跟随当前颜色），深色模式自动变浅。
- 选中/强调态：描边不变 + 一个糖果色填充块（双色）。
- 共 48 个，清单见 `附录B-图标清单.md`。

### 7.2 项目贴纸图标

- 画板 64×64，内容区 56×56。
- 2.5px 可可色墨线 + 2–3 个色块 + 左上 1 处白色高光，不用渐变。
- 放在彩色块上时：外加 3px 白色描边 + 向下 2px 的浅阴影，像贴上去的贴纸。
- 暂停/禁用态用脚本生成的灰度版本。
- 共 106 个，8 个分类，清单见 `附录B-图标清单.md`。

### 7.3 徽章

- 画板 200×200，结构见 `01-技术方案.md` 第 9.2 节。
- 12 种底座（每个系列一种）、4 种等级配色：花苞（蜜桃铜）、小花（薄荷银）、繁花（柠檬金）、彩虹花（多彩）。
- 数字用"徽章数字"字形拼接，不用文字。
- 每枚徽章交付分层 SVG（光芒、底座、缎带、图案、数字、星星分别成组）。

### 7.4 花朵三态（签名元素）

| 状态 | 形态 | 用在 |
|---|---|---|
| 小圆点 | 直径 5px，墨 200 | 有计划但没完成的过去日期 |
| 花苞 | 水滴形粉色花苞 + 两片薄荷花萼 | 部分完成 |
| 盛开 | 5 片圆瓣 + 柠檬色花心 | 全部完成；花心上有一张小笑脸（只在 ≥ 32pt 的大尺寸显示） |

### 7.5 心情表情（5 个）

超开心（星星眼）、开心（弯眼笑）、平静（眯眼微笑）、有点累（下垂眼 + 汗滴）、难过（泪滴）。分别用柠檬、莓果、薄荷、汽水、葡萄色作脸底。

## 9. 动效规范

### 9.1 参数

| 类别 | 值 |
|---|---|
| 时长 | 即时 80ms（按下）、快 140ms（颜色和状态）、标准 240ms（面板、切换）、舒缓 360ms（进入）、庆祝 900–1600ms |
| 缓动 | 标准 (0.2, 0.8, 0.2, 1)；进入 (0, 0, 0.2, 1)；退出 (0.4, 0, 1, 1) |
| 弹簧 | 按压：阻尼 18、刚度 420、质量 0.6；弹跳：阻尼 11、刚度 260；柔和：阻尼 20、刚度 180 |

### 9.2 原则

1. 动效用来解释发生了什么：开花 = 完成、收拢 = 撤销、飞走 = 收进成就馆、睡着 = 暂停。
2. 一屏同时最多一个庆祝级动效。
3. 不做无意义的循环；只有徽章弹窗和徽章详情的光芒慢转、空状态朵朵的轻微呼吸（幅度 ≤ 2%）可以循环。
4. 进入页面只有一次淡入上移（8px、240ms，子元素间隔 40ms，最多 6 个）。
5. 只动位置、缩放、旋转、透明度和 SVG 属性，不动宽高和边距。

### 9.5 减弱动态

系统开启"减弱动态效果"时：所有位移、缩放、弹簧换成 160ms 淡入淡出；不播放花瓣雨、彩纸、光芒旋转；花苞直接切换到盛开。

## 10. 文案规范

### 10.1 语气

像身边温柔的好朋友：轻快、具体、不说教、不卖惨。有昵称时问候语带昵称。

### 10.2 格式

- 普通界面不用感叹号；庆祝场景最多一个。
- 按钮、标题、标签末尾不加句号。
- 数字和单位之间加一个空格："3 天""86%"（百分号不加空格）。
- 日期写"11月22日 周日"，不是今年时加年份"2025年11月22日"；"今天""昨天"优先。
- 按钮用动词短语："种下它""收下啦""再来一轮""去设置"。

### 10.3 禁止出现在界面上的文字

1. 解释界面本身的文字，例如"这里是你的项目列表""下方展示了本月的统计数据"；
2. 开发占位和调试文字，例如"示例""测试""TODO""Lorem"、英文报错原文；
3. 写给 AI 或开发者看的描述、提示词式文字；
4. 责备或制造焦虑的话，例如"你又断签了""已经 3 天没来了"；
5. 空泛口号，例如"提升效率""优化体验"；
6. emoji 和颜文字。

### 10.4 对照示例

| 不要 | 改成 |
|---|---|
| 暂无数据 | 还没有打卡记录，去今天种下第一朵花吧 |
| 操作成功 | 记下啦 |
| 确定删除吗？ | 删除「早睡」？会同时删除 56 条打卡记录，心情会保留 |
| 您已连续中断 5 天 | 欢迎回来，今天重新开花 |
| 提交 | 种下它 |
| 这里展示了你的所有徽章 | （不需要这句话，直接展示徽章） |

完整文案库见 `附录C-文案库.md`。

## 11. 无障碍

- 正文对比度 ≥ 4.5:1，大字和图形 ≥ 3:1（色板已按此校验）。
- 点击区域 ≥ 44×44pt；花苞按钮 52pt。
- 所有图标按钮有读屏描述，例如"为早睡打卡，今天 0/1 次"。
- 系统字体放大到 1.3 倍不破版；更大时列表项允许换行，日历数字不放大。
- 状态不只靠颜色区分：花苞和盛开形状不同，暂停有睡觉角标。
- 支持减弱动态（见 9.5）。
