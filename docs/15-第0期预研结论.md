# 第 0 期 · 技术预研结论

对应 `01-技术方案.md` 第 20 节。结论用于指导第 1–4 期选型；若后续实测推翻，在对应期文档里修订。

| 风险 | 结论 | 采用方案 | 备注 |
|---|---|---|---|
| 日历折叠 + 列表嵌套滚动手感 | 可行，但首期成本偏高 | **第 1 期先做「月/周按钮切换」**；折叠手势列为第 4 期打磨项。Reanimated 4 + Gesture Handler 3 已接入，具备后续升级条件 | 中端安卓上嵌套滚动+折叠同时做，掉帧风险高于收益 |
| SVG 徽章动画性能 | 单枚复杂 SVG + 少量粒子可接受；72 枚同时动画不可行 | **成就馆网格用静态 / 简化徽章**；解锁弹窗才播完整动画。徽章引擎第 3 期按「网格简版 / 弹窗完整版」双档输出 | 第 0 期 SVG 管线已支持灰度与注册表 |
| 中文圆体字体 | 方圆体授权与包体未闭环；Fredoka 已验证可用 | **1.0 标题暂用系统粗体**；数字用 Fredoka（OFL）。方圆体接入条件：商用授权确认 + 子集化后体积可接受 | `ui/tokens/typography.ts` 已预留 `fontFamily.display` |
| iOS 交互小组件 | 需付费开发者账号 + App Group + App Intent；Expo 需 config plugin / 原生扩展 | **第 4 期做可打卡小组件**；若 Intent 在目标机型不稳，降级为「只展示，点击打开 App」 | 账号开通前无法真机签扩展，E0-12 先跑通主 App 分发 |
| Android 提醒到达率 | 精确闹钟权限因不上架 Play 可声明 `USE_EXACT_ALARM`；国产 ROM 仍可能杀后台 | **第 2 期用 expo-notifications + 精确闹钟**；保留自研原生排期为备选。出厂前在 2–3 款国产机实测到达率 | 小组件打卡后当日已排提醒可能仍响一次，接受并在文案中说明 |
| 移除网络权限 | 正式包可去掉网络权限；Expo / EAS 更新、部分诊断能力会受影响 | **正式包移除网络权限**（`AndroidManifest` 通过 config plugin 剥离）；内测/开发包保留以便装包与调试。代码层不发业务请求 | 与「数据不出手机」产品承诺一致 |

## 附带工程结论

- Expo SDK 58 + RN 0.88 + 新架构可用；路由用 Expo Router（`src/app`），标签栏用 `expo-router/ui` 自绘。
- 本地库：`expo-sqlite`（含 kv-store）满足主库 + 偏好；迁移前备份已在 migrator 落地。
- 动效：Reanimated 4.7 + worklets；花苞按钮 M02/M03/M04/M27 已在组件陈列页可验收。
- 深色模式：语义色双套已进 `ui/tokens`，组件陈列页可切换预览；完整视觉走查仍在第 4 期。
