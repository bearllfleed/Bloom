## 2. 页面

### 2.1 标签栏与占位页

```
┌──────────────────────────────────────┐
│                                      │
│                                      │
│           （朵朵 · 期待表情）           │
│              这里快要开花了             │   ← 仅开发期占位，第 1 期替换
│                                      │
│                                      │
├──────────────────────────────────────┤
│  [今日]   [项目]   [统计]   [成就]   [我的] │
│   今日     项目     统计     成就     我的  │
└──────────────────────────────────────┘
```

- 标签栏：高 64 + 安全区，白色 96% 底，顶部 1px 墨 200 分隔线。
- 图标 28：今日（日历上一朵花）、项目（花盆）、统计（花瓶里的三枝花，高低不同）、成就（奖章）、我的（朵朵头像）。
- 选中：图标由描边变为双色填充，播放 M09 弹跳，文字莓果 700；未选中文字墨 600。
- 再次点击当前页签：滚动回顶部；在今日页还会回到今天。
- 切换页签时页面不做转场动画（与系统习惯一致），只有图标动。

## 3. 花苞按钮详细规格（本期必须做到位）

这是整个 App 最高频的交互，第 0 期在组件陈列页里把它做到可以签字的程度。

| 状态 | 外观 | 点击行为 |
|---|---|---|
| 待打卡 | 奶油圆底 + 墨线；中间闭合的粉色花苞和两片薄荷花萼 | 打卡，播放 M02（单次）或 M03（多次的中间一次） |
| 分段进度 | 外圈 N 段描边，已完成段为项目深色，未完成段为墨 200 | 再打一次 |
| 已完成 | 5 瓣盛开的花，花瓣为项目底色，柠檬花心 | 打开"已完成"小菜单（撤销一次 / 写成绩 / 写心情） |
| 已达标（周期型） | 盛开 + 右下小勾 | 累计次数类：再打一次；任选几天类：当天未完成则打卡，已完成则打开小菜单 |
| 不可打卡 | 待打卡外观 40% 透明 | 播放 M27 轻摇 + 提示原因 |

- 点击热区 56×56（视觉 52）。
- 0.25 秒内的重复点击忽略。
- 动效分解（M02，共 520ms）：
  - 0–80ms：按压缩小到 0.88（按压弹簧）；
  - 80–260ms：膨胀到 1.12，花萼分别旋转 ±35° 张开；
  - 160–420ms：5 片花瓣按 30ms 间隔从 0.3 放大到 1，同时各自旋转到最终角度；花心在 300ms 弹出；
  - 200–520ms：8 片小花瓣沿放射方向飞出 24–40px 并淡出；
  - 与此同时卡片底色由按钮中心向外圆形扩散（360ms，进入缓动）。
- 读屏描述："为喝水打卡，今天 3/8 杯"；完成后"喝水今天已完成，双击查看选项"。

## 4. 验收标准

### 4.1 功能断言

| 编号 | 断言 |
|---|---|
| A0-01 | 给定内测版安装包，当在 iPhone（iOS 17+）和安卓手机（Android 8+）安装，则都能打开并看到 5 个页签 |
| A0-02 | 给定同一签名的新版本，当覆盖安装，则数据库中的测试数据保留 |
| A0-03 | 给定规则引擎，当运行单测，则 ≥ 150 个用例全部通过，领域层覆盖率 ≥ 90%，且覆盖 `01-技术方案.md` 7.3 全部场景 |
| A0-04 | 给定数据库从 v1 迁移到测试用 v2，当迁移脚本故意抛错，则数据库自动还原为 v1 且 App 可正常打开 |
| A0-05 | 给定开启时间旅行到 30 天后，当打开任意页面，则所有"今天"都是模拟日期，顶部有模拟提示条 |
| A0-06 | 给定任一 SVG 含 `<text>` 或内嵌位图，当运行构建，则构建失败并指出文件名 |
| A0-07 | 给定组件陈列页，当逐个点击所有组件，则每个状态与组件稿一致 |
| A0-08 | 给定在页面组件中直接引入数据库模块，当运行 ESLint，则报错 |
| A0-09 | 给定"导出诊断日志"，当导出，则文件中不含任何项目名或心情内容 |
| A0-10 | 给定组件陈列页开启"深色预览"，当逐个查看组件，则没有任何组件仍显示浅色硬编码颜色 |

### 4.2 体验与性能

- 中端安卓手机（如红米 Note 系列）录屏：花苞绽放、分段控件、开关、面板弹出全程无可见掉帧。
- 花苞按钮从手指抬起到动画开始 ≤ 50ms。
- 开启系统"减弱动态效果"后，花苞直接切换为盛开，无飞散花瓣。

### 4.3 设计

- 设计方向签字。
- 组件稿与组件陈列页逐项对照无差异。
- 视觉走查清单（设计规范第 12 节）中与组件相关的项全部通过。
