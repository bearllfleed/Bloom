# Bloom 内测安装说明

适用版本：第 1 期核心打卡闭环（`0.1.x`）。三种构建可同时装在同一台手机上，互不覆盖。

| 构建 | 显示名 | 包名后缀 | 用途 |
|---|---|---|---|
| development | Bloom 开发 | `.dev` | 组件陈列、时间旅行 |
| preview | Bloom 内测 | `.preview` | 给测试同学 |
| production | Bloom | （无） | 接近正式环境 |

## 构建命令

需已登录 EAS（`bunx eas-cli login` 或 `npx eas-cli@latest login`），并配置好 Apple / Google 凭证。

```bash
# iOS 内测（TestFlight / 内部发行）
npx eas-cli@latest build --platform ios --profile preview

# Android 签名 APK
npx eas-cli@latest build --platform android --profile preview

# 开发版（含开发客户端）
npx eas-cli@latest build --platform all --profile development
```

本地调试（模拟器 / 已装开发客户端）：

```bash
npx expo start
```

### 本机打 Android 安装包（不经过 EAS）

需要 JDK 17、Android SDK（含 NDK 27.1.12297006、CMake 3.22.1、Build-Tools 37）。包内自带 JS，不依赖开发服务器。

```bash
npx expo prebuild --platform android
cd android
EXPO_PUBLIC_APP_VARIANT=development NODE_ENV=production \
  ./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a
# 产物：android/app/build/outputs/apk/release/app-release.apk
adb install -r app/build/outputs/apk/release/app-release.apk
```

- `EXPO_PUBLIC_APP_VARIANT` 决定包名后缀与是否带开发工具，换成 `preview` 即内测版。
- 只给 arm64 设备（真机、Apple 芯片上的 BlueStacks）用时加 `-PreactNativeArchitectures=arm64-v8a`，编译快很多。
- 本机 release 包用调试签名，只适合自测；给别人装请用正式签名（见下文"签名与密钥保管"）。

## iOS 安装

1. 开通 [Apple 开发者账号](https://developer.apple.com)（个人约 688 元/年；审核通常 1–2 天）。
2. 在 App Store Connect 创建 App，Bundle ID 与 `app.config.ts` 中一致（占位 `com.bloom.habit` / `.preview` / `.dev`，开通后请改成自己的反向域名，之后不要再改）。
3. `eas build --platform ios --profile preview` 完成后，用 `eas submit` 传到 TestFlight，或在 EAS 后台用内部发行链接安装。
4. 测试机打开 TestFlight → 接受邀请 → 安装「Bloom 内测」。
5. **覆盖安装会保留数据**；卸载会清空全部本地数据。

Ad Hoc 备选：收集设备 UDID，用 Ad Hoc 描述文件分发；每年最多 100 台。

## Android 安装

1. 首次构建前生成签名密钥，**备份到两个地方**（密钥丢失则无法覆盖更新）：
   ```bash
     npx eas-cli@latest credentials -p android
   ```
2. 构建完成后下载 APK。
3. 手机设置 → 允许「安装未知来源应用」（各品牌路径略有不同）。
4. 用文件管理器打开 APK 安装。
5. 鸿蒙 NEXT（纯血鸿蒙）无法安装 APK。

## 签名与密钥保管

- iOS：证书与描述文件由 EAS 托管时可在苹果后台撤销重签；本地导出的 `.p12` 需双份备份。
- Android：`.jks` / `.keystore` 与密码双份备份；丢失只能换包名或卸载重装。
