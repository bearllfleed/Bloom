# Bloom 第三期剩余功能实施设计

日期：2026-11-25
状态：用户已确认沿用现有四份产品与技术规格直接连续实现，不逐页审批。

## 目标与边界

在已完成的 3-1 成就判定和心情照片处理基础上，交付 3-2～3-10。包括徽章视觉与展示、完整心情流程、跨页面联动和带照片的备份往返。小组件徽章不在本期接入。

## 实现单元

### 1. 徽章视觉引擎（3-2）

文件：`src/ui/badges/`、`tests/ui/badgeVisuals.test.ts`。

沿用主题色板和 `ui/motion`：实现 12 种底座、4 档等级配色、路径数字、72 枚可辨识的独立图案，不用文字、emoji 或位图代替图形。提供 `Badge` 的 `static / idle / celebrate` 三模式；静态网格不启动循环，详情和弹窗使用 Reanimated。减弱动态时只保留 160ms 淡入淡出。未获得采用墨色剪影，隐藏未获得使用礼盒问号。

### 2. 心情持久化与备份（3-8、3-10 数据部分）

文件：`src/domain/mood/`、`src/data/repositories/moodRepo.ts`、`src/services/moodService.ts`、`src/platform/files.ts`、`src/services/backupService.ts`、`tests/domain/mood.test.ts`、`tests/data/backupFormat.test.ts`。

领域层限制正文 Unicode 字符数 500、照片数 5，计算保存可用性、草稿键和变更标记。仓储保持 `(date, projectId|null)` 唯一；项目删除后保留名称快照，撤销打卡不删除心情。编辑事务先替换照片元数据，再删除孤立文件；删除心情同时清理照片文件。

草稿使用现有偏好键值存储，2 秒定时和进入后台时保存，保存或明确放弃时清除。粘贴超限截断并提示。处理中的照片、失败可重试的照片只存编辑态，不把临时 URI 当已保存照片。

`.bloom` 继续沿用当前格式 v1（v1 已预留 moods/moodPhotos），增加 `media/mood/<file_name>` 原图与缩略图条目和路径白名单。导出和导入逐文件 SHA-256 校验；恢复先写入新目录，数据库事务成功后再原子替换媒体目录，失败清理新目录并保留旧文件。预览补齐徽章数。

### 3. 成就展示（3-3～3-6）

文件：`src/features/achievement/`、`src/app/(tabs)/achievements.tsx`、`src/app/dev/badges.tsx`、根布局和页签集成。

全局弹层队列继续决定完美日、毕业典礼和徽章的先后。补发卡展示静默结算或一次 ≥5 枚的队列，否则逐枚弹窗；支持进度点、一次收下、跳成就馆定位、Android 返回收下。收下后再标 `seen`，进程退出后未展示队列仍在数据库。详情面板支持同系列切换、获得信息、当前进度、神秘条件遮蔽，以及拖动倾斜和点击重播。成就馆提供总数、花藤进度、最近获得、筛选、12 系列三列静态网格和新徽章圆点。开发陈列覆盖 72 枚 × 三模式。

### 4. 心情界面与入口（3-7～3-9）

文件：`src/features/mood/`、`src/app/mood/`、今日卡片与标题、完美日、我的。

心情入口只在项目当天完成或已有心情时出现；项目卡片菜单提供写/看心情，标题行在完美日或已有当天心情时出现，完美日横幅提供按钮，不自动弹编辑页。编辑器支持五种 SVG 表情、文字、照片排序/删除/重试/查看、保存与离开确认、已有心情删除。

手账按月吸顶，支持全部/只看有照片，便签奇偶 ±1°，空状态使用朵朵写日记姿势。详情展示全文和 1/2/3–5 张响应式网格。图片查看全屏滑动切换，顶部索引，支持双击缩放、双指缩放、下滑关闭；无专用图片组件时使用 RN Image + 手势与 Reanimated，不新增未经 Expo 验证的依赖。

### 5. 联动与验证（3-10）

历史记录行显示迷你表情并可打开详情；毕业回顾增加相关徽章和最多 3 张心情缩略图；年度统计增加徽章数；备份预览显示心情、照片、徽章数。

## 顺序与隔离

先由独立实现任务完成徽章视觉和心情数据，主线程随后集成成就展示、心情页面及跨页面入口。实现任务只写各自文件；集成和审查在主线程完成。不会并行修改同一文件。
