#### 模块说明

**顶栏**
- 左侧朵朵头像 40pt，表情随今天进度变化（设计规范第 2 节）。点击播放 M28，冒出一句随机鼓励语。
- 问候语按时段：5:00–10:59 早上好、11:00–13:59 中午好、14:00–17:59 下午好、18:00–22:59 晚上好、23:00–4:59 夜深了；有昵称时加"，小桃"。
- 第二行固定显示今天的日期（不随选中日期变化）。
- 右侧两个 40pt 圆形白底按钮：历史（时钟图标）→ 打卡记录；新建（加号）→ 创建项目。

**日历**
- 日期格规格见设计规范第 8 节。花朵标记按当天"完成项目数 ÷ 计划项目数"：没有计划不显示；过去且 0 完成显示小圆点；部分完成显示花苞；全部完成显示盛开。未来日期不显示标记。
- 左右滑动切月（M06）。可滑动范围：最早项目开始日期所在月（没有项目时为本月）到 12 个月后；到边界时橡皮筋回弹。
- "回到今天"胶囊：选中日期不是今天、或显示的不是本月时出现；点击滑回本月并选中今天。
- 月/周切换：点右上切换图标，或拖动把手/列表（M07）。
- **嵌套滚动**：日历展开时向上滑动列表，先折叠日历，折叠完成后列表才开始滚动；日历折叠且列表在顶部时向下拉，展开日历。
- 首页视图默认月视图，此后记住用户上次的选择。

**列表标题行**
- 选中今天显示"今天 · 完成 1/3"，昨天显示"昨天 · 完成 2/3"，其他显示"11月20日 周五 · 完成 3/3"；未来日期显示"11月25日 周三 · 有 3 个计划"。
- 全部完成时文字变为"今天的花全开啦"，莓果 700。

**项目卡片**

| 区域 | 规格 |
|---|---|
| 尺寸 | 最小高 76，内边距 16，圆角 20，白底，底部厚边 4px |
| 左 | 48pt 圆形浅色底 + 44pt 贴纸图标 |
| 中 | 第一行项目名（标题 3）；第二行副文案（辅助号，墨 600，单行省略） |
| 右 | 花苞按钮 52pt |

副文案规则：

| 情况 | 副文案 |
|---|---|
| 单次项目、未完成 | 鼓励语 |
| 多次项目、未完成 | 今天 3/8 杯 |
| 周期型、未达标 | 本周 2/3 天 / 本月 5/12 次 |
| 周期型、已达标 | 本周已达标 |
| 已完成 | 已完成 07:55（多次项目取最后一次时间） |
| 未来日期 | 鼓励语（花苞按钮为不可打卡态） |

- 列表顺序 = 项目页里的排序；完成后不改变位置（避免连续点击时目标跑掉）。
- 点卡片空白处 → 项目详情；点花苞 → 打卡；长按卡片 → 菜单（撤销一次、写成绩、查看详情）。
- 卡片按下缩小到 0.98，花苞按钮有独立的按压反馈，两者不会同时触发。

#### 打卡交互

| 操作 | 结果 |
|---|---|
| 点击待打卡花苞（单次项目） | 播放 M02，触感轻触；卡片变为已完成；底部出现撤销条"早睡 · 打好卡啦 撤销"（3 秒） |
| 点击多次项目的中间一次 | 播放 M03，触感选择；撤销条"喝水 · 4/8 杯 撤销" |
| 点击多次项目的最后一次 | 播放 M02 |
| 点击已完成花朵 | 在花朵旁弹出气泡菜单：撤销一次 / 写成绩（开启成绩时）；点外部关闭 |
| 点击撤销条或菜单"撤销一次" | 删除该项目当天最近一条记录，播放 M04，触感柔和 |
| 点击未来日期的花苞 | 播放 M27，触感警告，提示"还没到这一天哦"，不产生记录 |
| 选中过去的日期后点击 | 与今天完全相同（补卡），不弹任何提示 |
| 0.25 秒内重复点击 | 忽略第二次 |
| 写入失败（极少） | 花朵收回，提示"没打上，再试一次" |

#### 完美日庆祝

- 选中日期的所有"必须打卡"项目首次全部完成时播放 M05：朵朵跳起、花瓣雨、日历格的花弹一下、顶部横幅"今天的花全开啦"（4 秒后自动收起，可上滑关闭）。
- 同一天只在第一次达成时播放；撤销后再完成不再重复播放。
- 补卡让过去某天变成完美日时，只播放日历格的花弹一下，不放花瓣雨。
- 若同时要弹出成绩面板，先弹成绩面板，面板关闭后再播放庆祝。

#### 状态

| 状态 | 列表区域显示 |
|---|---|
| 没有任何项目 | 日历自动切为周视图；朵朵捧种子 + "种下第一颗种子" + 主按钮"去种花" + 4 个模板芯片（喝水、早睡、读书、运动），点模板进入预填好的创建页 |
| 当天没有计划（休息日） | 朵朵躺云朵 + "今天没有安排，好好休息一下" + 文字按钮"看看全部项目" |
| 选中日期早于所有项目 | 朵朵疑惑表情 + "那时候还没有种下小花" |
| 选中未来日期 | 列出当天计划的项目，花苞为不可打卡态 |
| 跨过零点 | 回到前台时，若之前选中的是"今天"，自动切到新的今天；若选中的是其他日期则不动 |

### 1-3 创建/编辑项目

全屏模态，从底部滑入；可下滑关闭。

```
┌──────────────────────────────────────┐
│ (关闭)          新的小目标               │
├──────────────────────────────────────┤
│ ┌──────────────────────────────────┐ │
│ │          （贴纸图标 88pt）           │ │  底色 = 所选颜色的浅色
│ │              换个图标                │ │  点击整块打开图标选择
│ │ ● ● ● ● ● ● ● ● ● ● ● ●            │ │  12 个颜色圆点
│ └──────────────────────────────────┘ │
│           想坚持做点什么                  │  名称输入，标题 1 字号，居中
│        ──────────────────              │
│ [早睡] [喝水] [背单词] [运动] [读书] …     │  模板芯片：仅新建且名称为空时显示
│ ┌──────────────────────────────────┐ │
│ │ (图标) 打卡频率        每天 1 次   > │ │
│ │ (图标) 开始日期          今天     > │ │
│ │ (图标) 坚持多久        一直坚持    > │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ (图标) 给自己的一句话   (骰子) 换一句 │ │
│ │ ┌──────────────────────────────┐ │ │
│ │ │ 慢慢来，比较快            7/40   │ │ │
│ │ └──────────────────────────────┘ │ │
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ (图标) 打卡时记录成绩        (开关)  │ │
│ └──────────────────────────────────┘ │
│ [              种下它              ]   │  固定在底部，随键盘上移
└──────────────────────────────────────┘
```

**默认值**：频率每天 1 次；开始日期今天；坚持多久一直坚持；图标"小花"；颜色草莓；鼓励语随机一句；成绩关闭；单位"次"。

**交互细节**
- 打开时不自动弹键盘，让模板芯片可见；点名称后再输入。
- 名称 ≤ 20 字；输入到 15 字起显示"15/20"。提交时为空：输入框轻摇，下方出现"先给它起个名字吧"。
- 点模板：一次性填好名称、图标、颜色、频率、单位、鼓励语；模板芯片收起；所有项仍可修改。
- 选图标后，若用户没手动选过颜色，颜色跟随图标分类的推荐色；手动选过颜色后不再自动改。
- 颜色切换：头部底色 240ms 交叉过渡，选中圆点出现外圈和小勾。
- 换一句：M24，从文案库随机取一句不重复的。
- 点"种下它"：校验通过后关闭模态，回到今日页，新卡片位置播放 M11 并滚动到可见。
  - 开始日期在未来：回到今日页，提示"「晨跑」会在 11月25日 开始"。
- 有改动时关闭（点关闭或下滑）：确认框"放弃这次编辑吗"，按钮"继续编辑 / 放弃"。

**编辑模式差异**
- 标题"编辑「早睡」"，按钮"保存"，不显示模板。
- 打卡频率改动后，该行下方出现一行辅助文字："从今天起按新频率计算"。
- 开始日期：可选范围截止到最早一条记录的日期，之后的日期置灰，点击置灰日期提示"最早的记录在 11月18日"。
- 已毕业项目：频率、开始日期、坚持多久三行置灰，点击提示"毕业后不能再改啦"。
- 保存后返回上一页，提示"改好啦"。

- 各分段默认值：每天 → 每天 1 次；每周 → 任选 3 天；每月 → 任选 10 天。切换分段时保留各自上次的选择。
- 点任一周几芯片自动选中"固定几天"。
- 预览句随任何改动更新：旧句向上淡出，新句从下方淡入。

- 选了 29/30/31 号：下方出现"没有这一天的月份，会在当月最后一天打卡"。
- 步进器长按加速，到上下限时数字轻摇一次。
- 自定义单位：弹出小输入框，≤ 2 字。

#### 1-3b 开始和时长面板

点"开始日期"或"坚持多久"都打开这个面板，分别滚动到对应部分。

```
┌──────────────────────────────────────┐
│ 从哪天开始                              │
│ [今天] [明天] [下周一] [选日期]            │  选日期时在下方展开月历
│ ─────────────────────────────         │
│ 坚持多久                               │
│ [一直坚持] [7 天] [21 天] [1 个月]         │
│ [3 个月]   [半年] [1 年]  [选截止日期]     │
│ ─────────────────────────────         │
│ 11月22日 到 12月12日，共 21 天            │  预览句
│ [              好的              ]     │
└──────────────────────────────────────┘
```

- 开始日期可选过去任意日期（用于补录），未来最多 1 年。
- 时长计算：N 天 → 截止 = 开始 + N − 1 天；N 个月/年 → 截止 = 开始加 N 个月/年再减 1 天。
- 截止日期必须 ≥ 今天且 ≥ 开始日期；按所选开始日期算出的截止日期已早于今天时，该时长芯片置灰，点击提示"已经过去啦"。
- 一直坚持时预览句为"从 11月22日 开始，一直坚持"。

### 1-4 成绩面板

项目开启"记录成绩"后，打卡完成的那一下（单次项目每次、多次项目当天最后一次、累计次数类每次）在 M02 结束 400ms 后弹出。

```
┌──────────────────────────────────────┐
│                ━━━━━                  │
│ 今天的成绩 · 跑步                        │
│ ┌──────────────────────────────────┐ │
│ │ 记下今天的数据或感受                  │ │  占位文字
│ │                                  │ │
│ │                           0/200  │ │
│ └──────────────────────────────────┘ │
│ 跳过                      [ 记下来 ]   │
└──────────────────────────────────────┘
```

- 弹出时自动聚焦并弹键盘。
- 跳过或下滑关闭：打卡照常有效，不保存备注。
- 记下来：备注挂在这次打卡记录上，提示"记下啦"。
- 补卡时标题显示"11月20日的成绩 · 跑步"。
- 之后可在打卡记录、项目详情的某天面板里修改。
