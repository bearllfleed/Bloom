## 2. 页面设计

### 2-1 提醒设置面板

入口：创建/编辑项目表单新增的"提醒"行（位于"坚持多久"下方）。行内显示"08:00、21:30"或"未设置"；通知权限未开时显示提醒色"通知未开启"。

```
┌──────────────────────────────────────┐
│                ━━━━━                  │
│ 提醒                                   │
│ ┌──────────────────────────────────┐ │
│ │ 08:00                (开关) (删除)  │ │
│ │ 21:30                (开关) (删除)  │ │
│ └──────────────────────────────────┘ │
│ (＋) 添加提醒时间                        │  满 5 个后隐藏
│ ─────────────────────────────         │
│ 当天完成后不再提醒              (开关)     │
│ 本周达标后不再提醒              (开关)     │  仅周期型项目显示
│ ─────────────────────────────         │
│ 只在每周一、三、五提醒                     │  固定几天/几号类显示
│ [              好的              ]     │
└──────────────────────────────────────┘
```

- 添加：弹出系统时间滚轮，默认为下一个整点（模板自带时间时用模板时间，如早睡 22:30）。重复时间提示"这个时间已经有啦"。
- 删除：行向左滑出，无确认（面板点"好的"前都可以再加回来）。
- **第一次添加提醒时的权限流程**：

```
┌──────────────────────────────────────┐
│          （朵朵 · 摇铃铛 120）           │
│          到点了我来敲敲你                 │
│   只用来提醒你打卡，不会发别的消息          │
│   [          好呀          ]           │  → 系统权限弹窗
│             先不用                      │
└──────────────────────────────────────┘
```

  - 选"先不用"或系统里拒绝：提醒照常保存，表单行显示"通知未开启"，点击跳到提醒检查页。

### 2-2 提醒检查页

入口：我的 → 提醒检查；表单里"通知未开启"；有问题时"我的"页该行右侧出现提醒色小圆点。

```
┌──────────────────────────────────────┐
│ (返回)           提醒检查                │
│ ┌──────────────────────────────────┐ │
│ │ （朵朵 · 摇铃铛）  都设置好啦          │ │  有问题时："还有 1 项要设置"
│ │                 提醒会准时到          │ │
│ └──────────────────────────────────┘ │
│ (勾)   通知权限                 已开启   │
│ (叹号) 精确闹钟                去开启 >  │  仅 Android 12+
│ (叹号) 后台运行（小米）         去设置 >  │  仅识别到的国产品牌
│        ① 设置 → 应用设置 → 应用管理 → Bloom│  点击行展开 3 步说明
│        ② 省电策略 → 无限制               │
│        ③ 自启动 → 打开                   │
│ ─────────────────────────────         │
│ 晚间汇总提醒             21:30  (开关)   │
│ ─────────────────────────────         │
│ [      发一条测试提醒（5 秒后）     ]     │
│ 接下来的提醒                             │
│ 今天 21:30  早睡                         │
│ 明天 08:00  喝水                         │
│ ……（最多 10 条）                         │
│ 提醒有点多，记得每两天打开一次 Bloom         │  仅排期覆盖不足 3 天时显示
└──────────────────────────────────────┘
```

- 每一项检测结果实时刷新（从系统设置返回 App 时重新检测）。
- 品牌识别覆盖：小米/红米、华为、荣耀、OPPO/一加/realme、vivo/iQOO、三星；每个品牌的 3 步说明写在文案库，"去设置"按钮尝试打开对应设置页，失败则打开本 App 的系统设置页。
- iOS 只显示"通知权限"一行，并在下方注明"专注模式开启时提醒可能不会响"。
- 测试提醒：点击后提示"5 秒后会收到一条提醒，可以先回到桌面"，内容"朵朵来敲门啦，提醒一切正常"。
- 晚间汇总：开启后按需求 5.10 发送，内容如"还有 2 个小目标在等你：早睡、喝水"。

**通知点击**：打开今日页，选中今天，滚动到对应项目，卡片轻弹一次（1.02 倍，一次，不循环）。晚间汇总则滚动到第一个未完成的项目。

**通用规则**

- 没有任何记录：朵朵 + "打卡之后，这里会长出你的花园" + 按钮"去打卡"。

```
│ │   └───────┴───────┴────────┘       │ │

└──────────────────────────────────────┘
```

**动效时间线（约 2 秒）**

| 时间 | 动作 |
|---|---|
| 0ms | 点阵纸背景整屏淡入（200ms） |
| 150ms | 朵朵从底部弹入 |
| 300–800ms | 证书从顶部展开（纵向从 0.05 拉到 1，末尾纸张轻弹） |
| 800–1200ms | 证书内容依次淡入，数字滚动 |
| 1300ms | 盖章 M23，触感重击 |
| 1400–2000ms | 两侧上角喷出彩带并飘落 |
| 1500ms | 按钮淡入 |

- 没有昵称时写"颁发给 你"。
- 按钮："回顾这段旅程"→ 回顾页；"再来一轮"→ 2-7；"收下证书"→ 关闭，若还有下一个毕业项目则 300ms 后开始下一个。
- Android 返回键 = 收下证书。不支持点背景关闭。
- 减弱动态：证书直接显示，无彩带、无盖章动画。

**导出流程**
1. 点"导出备份文件" → 面板"正在打包"，花瓣逐片填满表示进度，下方"5 个项目 · 268 条记录"。

**导出表格**：生成"打卡记录.csv"（日期、星期、项目、打卡时间、成绩）和"项目.csv"（名称、频率、开始、截止、状态、累计、完成率），一起发送。

### 2-9 导入预览、恢复、结果

1. 点"从备份恢复" → 系统文件选择器；也可从微信、文件 App 中直接点击 `.bloom` 文件打开。
2. 校验失败的提示：

| 情况 | 提示 |
|---|---|
| 不是备份文件 | 这个文件不是 Bloom 的备份 |
| 文件损坏 | 备份文件好像坏了，换一个试试 |
| 版本比 App 新 | 这个备份来自更新的版本，请先升级 Bloom |
| 空间不足 | 手机空间不够了，清理一下再试 |

3. 预览页：

```
┌──────────────────────────────────────┐
│ (返回)            恢复备份               │
│ ┌ 便签样式备份卡 ─────────────────────┐ │
│ │ 2026年11月10日 21:03 · 来自 iPhone   │ │
│ │ 5 个项目 · 240 条记录                │ │
│ │ 10 篇心情 · 18 张照片                │ │
│ └──────────────────────────────────┘ │
│ 恢复后，这台手机上现在的数据会被替换        │
│ 恢复前会先自动备份现在的数据               │
│ [          替换并恢复           ]        │
│               取消                      │
└──────────────────────────────────────┘
```

4. 点"替换并恢复" → 全屏"正在恢复"（不可取消），按 `01-技术方案.md` 12.2 执行。
5. 成功：朵朵撒花 + "欢迎回来，数据都回来啦" + 按钮"去看看"（回到今日页）。
6. 失败：朵朵疑惑 + "恢复没有成功，现在的数据没有变化" + 按钮"导出诊断日志"/"知道了"。

决策：只做一次确认（预览页按钮）。理由：恢复前有自动备份可退回，不需要再加一层确认框；若后续取消自动备份，需改为二次确认。
